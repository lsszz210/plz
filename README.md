# 주식 및 코인 분석 웹 애플리케이션

React 기반의 프론트엔드와 Node.js/Express 백엔드를 이용한 간단한 분석 도구입니다. 주식 심볼이나 코인 페어(btc/usd 등)를 입력하면 최근 1년간의 가격 데이터를 가져와 이동평균선, RSI, 간단한 회귀 예측 값을 반환합니다. 주식의 경우 재무 데이터도 함께 제공합니다.

## 실행 방법
1. 의존성 설치
   ```bash
   npm install
   ```
2. 서버 실행
   ```bash
   npm start
   ```
3. 브라우저에서 `http://localhost:5000` 접속
